# 童年游戏厅

**让家里的安卓电视，变成全家都能玩的复古游戏厅。**

当前版本：**1.0.1**（`versionCode 21`）。

游戏厅由三部分组成：电脑上的部署 Skill 负责下载、校验和安装；电视上的 APK 负责大厅、手柄和模拟器；游戏资源包保存 ROM/BIOS。部署完成后电视独立运行，玩游戏时不需要电脑一直开着。

## 有什么

目前收录 **179 款游戏、190 个游戏版本**，覆盖五个平台：

| 平台 | 示例 |
| --- | --- |
| 红白机 | 超级玛丽、魂斗罗、松鼠大战 |
| 街机 | 吞食天地Ⅱ、拳皇97、拳皇98、合金弹头 |
| GBA | 宝可梦、牧场物语、恶魔城 |
| 世嘉 MD | 索尼克2、暴力摩托、雷霆力量Ⅳ |
| 超级任天堂 SFC | 星之卡比 |

主要功能：

- 手柄、电视遥控器和手机触屏都能操作，支持双人合作入口。
- 收藏、最近玩过、首页排序，方便找游戏。
- 每个游戏 4 个即时存档位，支持自动存档与倒带。
- 备份与恢复：可导出到 U 盘，或通过手机局域网页面备份。
- 应用内检查软件更新；也可在设置中下载和更新游戏资源包。

## 需要准备什么

- **电视或电视盒子**：Android 6.0（API 23）或以上，ARM 架构。APK 同时包含 `armeabi-v7a` 与 `arm64-v8a`，仅支持 x86 的设备不能安装。
- **存储空间**：APK 约 17 MB，资源包约 375 MiB，解压后约 495 MiB；安装峰值还会占用额外空间，部署前会检查。
- **电脑与智能体**：智能体需要能安装 Skill、访问本机文件并执行命令。只有网页聊天功能的工具无法直接部署。
- **Python 3.9+ 与官方 ADB**：用于运行部署工具和连接电视，可先让智能体检查。
- **网络与手柄**：电脑和电视网络互通，通常使用同一个家庭路由器；准备兼容手柄。

详细要求、空间说明和排错见[使用指南](docs/使用指南.md)。

## 安装

### 1. 让智能体安装 Skill

把下面这段话发给电脑上的智能体：

> 请按你支持的 Skill 安装方式，安装这个仓库中的童年游戏厅部署技能：
> 仓库：https://github.com/fatherxu/childhood-arcade
> 技能路径：skills/childhood-arcade-tv
> 如果你不支持安装 Skill 或执行本机命令，请先告诉我。

安装方法因智能体而异，按工具要求重新开启会话或加载技能。

### 2. 告诉智能体安装到哪台电视

打开电视，查看网络设置中的 IPv4 地址，然后发送：

> 使用 childhood-arcade-tv，帮我把童年游戏厅安装到电视上，电视 IP 是：这里填写电视地址。

首次需要在电视上开启 **ADB 调试**，并用遥控器允许电脑连接。找不到入口时，告诉智能体电视品牌和型号，让它指导操作。

智能体会下载 APK 与资源、校验哈希并部署。只有 GitHub Release 中已发布的附件才能自动下载。

### 3. 打开游戏厅

部署完成后，在电视应用列表打开「童年游戏厅」。建议先试玩一款，确认画面、声音、操作和存档正常。

## 更新

电视能联网时，打开游戏厅 **设置 → 软件更新**，检查并安装新版本。也可以让电脑上的智能体执行更新：

> 帮我更新电视上的童年游戏厅。

更新包必须与已安装版本使用同一签名；签名冲突、备份失败或设备身份改变时，工具会停止，不会自动卸载或清除存档。应用内资源下载依赖 Release 中的资源包附件，若提示 404，说明对应版本尚未上传。

## 当前适配情况

已有指定小米电视（MiTV4-ANSM0、Android 6、2 GB RAM）与两只 SHANWAN 手柄的使用记录。部署脚本有 31 项单元测试；资源传输、备份恢复和中断回滚在隔离的 Android 30 ARM64 模拟器上验证过。

自动化只确认“安装成功、页面可见”，声音、流畅度、实体手柄和全部游戏仍需实机确认。新 Windows 电脑从零部署和 32 位 ARM 真机完整验收仍在进行。

反馈时请提供电视品牌型号、Android 版本、电脑系统、智能体名称、游戏名称、操作步骤和具体错误。详见[使用指南](docs/使用指南.md#测试范围与反馈)。
