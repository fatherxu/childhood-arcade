# 使用指南

本文面向安装和使用游戏厅的用户。开发、构建与发布流程见[开发指南](开发指南.md)，代码细节见[CodeWiki](CodeWiki.md)。

## 它是怎么工作的

| 组成 | 位置 | 作用 |
| --- | --- | --- |
| 部署 Skill | 电脑（智能体执行） | 下载、校验、安装、更新、备份与恢复 |
| APK | 电视 | 游戏大厅、手柄与触屏输入、模拟器调度、本地存档 |
| 游戏资源包 | 部署时传到电视 | ROM 与 BIOS 文件 |

用户不需要逐个安装游戏。部署完成后，大厅按平台调用相应模拟器内核，电视独立运行，不需要电脑持续开机。电脑和电视各自保存数据；游戏目录一致不代表存档自动同步。

同一款作品可能存在多个版本，因此“179 款游戏”对应“190 个游戏版本”。

## 准备

### 电视

- Android 6.0（API 23）或以上。
- ARM 架构：APK 同时包含 `armeabi-v7a`（32 位）与 `arm64-v8a`（64 位）。仅支持 x86 的设备不能安装。
- 建议预留 1 GB 以上可用空间。APK 约 17 MB，资源包约 375 MiB，解压后约 495 MiB；系统安装展开、传输临时文件和存档还会占用空间，脚本会检查剩余空间，但实际峰值因设备而异。

### 电脑

- 智能体必须能加载 Skill、访问本地文件并执行命令。不同产品的技能安装目录和调用方式不同，不能假设所有聊天工具都能安装。
- Python 3.9+。Windows 可使用实际安装的 `python` 或 `py -3`，其他系统通常使用 `python3`。
- Google 官方 Android Platform Tools（ADB）。
- 电脑和电视网络互通，建议连接同一个家庭路由器。

### 手柄

准备兼容手柄。蓝牙手柄先完成配对；不同品牌和游戏的支持情况不同，不能保证所有手柄直插即用。没有手柄时可用电视遥控器或手机触屏。

## 安装

### 通过智能体

1. 按智能体支持的方式安装 `skills/childhood-arcade-tv`。
2. 在电视上开启 ADB 调试，查看当前 IPv4 地址。
3. 对智能体说：

   > 使用 childhood-arcade-tv，帮我把童年游戏厅安装到电视上，电视 IP 是：这里填写电视地址。

4. 首次连接时用遥控器在电视上允许调试。找不到 ADB 入口时，告诉智能体电视品牌和型号。
5. 智能体会下载并校验 APK 与资源、覆盖安装、启动页面并截图。报告为 `installed_verified` 表示安装和页面显示已验证；声音、手柄和游戏体验仍需实机确认。

安装使用覆盖方式，不卸载、不清数据。遇到签名冲突、备份失败、空间不足或设备身份变化时会停止。

### 手动部署

没有 Release 附件或需要内网安装时，可先准备本地 APK 与资源包，再执行：

```sh
python3 scripts/tv.py configure --apk /绝对路径/app.apk --sha256 APK的SHA256 --game-pack-manifest /绝对路径/game-pack/manifest.json --transport provider
python3 scripts/tv.py deploy --serial 电视IP
```

Windows 按实际 Python 安装使用 `python` 或 `py -3`。完整命令见[开发指南](开发指南.md#部署命令)。

## 首次启动

- 应用列表中的名称是「童年游戏厅」。
- 首次进入可看三步引导；之后可用方向键、确定/返回键、手柄或遥控器操作。
- 设置页可调整画面比例、音量、手柄布局与死区、备份、导入游戏、检查更新、下载资源。
- 游戏内按返回键或手柄 `Select+Start` 打开暂停菜单。

## 更新

### 应用内更新

电视联网后打开 **设置 → 软件更新**，检查新版本并下载安装。更新包会校验 HTTPS 地址、大小、SHA-256、包名、`versionCode` 和签名；任一不符即停止。

### 通过智能体更新

> 帮我更新电视上的童年游戏厅。

工具会检查版本，并在覆盖安装前备份已保存进度。更新必须使用与当前安装一致的签名。签名冲突时不要卸载重试，否则会丢失存档；应先确认来源或导出备份。发行密钥丢失会影响后续所有更新。

## 游戏资源下载

如果 TV 端的资源不完整，可在 **设置 → 游戏资源** 中下载资源包。下载支持 HTTPS、断点续传、计量网络确认、剩余空间预检，整包和逐文件都会校验 SHA-256。

> 资源包地址来自 Release 中的 `childhood-arcade-games-<版本>.zip`。当前 1.0.1 对应的资源包版本为 1.0.0；如果该附件尚未上传，下载会返回 404，此时请使用电脑部署或等待资源包发布。

## 备份与恢复

备份包括设置、收藏、首页顺序、即时存档、电池存档和 NES SRAM；不包含 ROM，也不包含尚未保存的运行中进度。不同内核或不同游戏版本的即时存档不保证互通。

### 应用内导出与恢复

- 设置页可将备份导出为 JSON 文件，或通过手机局域网页面下载。
- 恢复前先停止游戏并在游戏中保存。恢复会覆盖备份中包含的同名已保存状态，其他游戏资源保留。
- 备份文件大小限制为 50 MiB（老电视的文件选择兜底路径为 8 MiB）。

### 电脑端备份与恢复

```sh
python3 scripts/tv.py backup --serial 电视IP --output /绝对路径/backup.json
python3 scripts/tv.py restore --serial 电视IP --input /绝对路径/backup.zip
```

`provider` 模式会生成 ZIP，即使输出名写 `.json` 也会改为 `.zip`。恢复前会核对设备身份和备份来源；失败会尝试回滚，应用重新启动时会处理中断的恢复事务。命令会停止游戏厅，不包含停止前未保存的进度。

## 测试范围与反馈

已完成：

- 部署脚本 31 项 Python 单元测试。
- 独立构建输入目录重建应用、签名检查和关闭调试状态检查。
- 隔离的 Android 30 ARM64 模拟器上，用去掉原生游戏库的传输专用包验证 52 项资源传输、备份恢复和恢复中断回滚。
- 小米电视 MiTV4-ANSM0（Android 6、2 GB RAM）与两只 SHANWAN 手柄的使用记录。

仍需验收：

- 本次发布构建在新 Windows 电脑上的从零部署。
- 32 位 ARM 真机上的完整游戏体验。
- 不同智能体、电视和手柄的组合兼容性。

反馈时请提供电视品牌型号、Android 版本、电脑系统、智能体名称、游戏名称、操作步骤和具体错误，并区分无法连接、安装失败、画面卡顿、声音断续和按键无反应。分享日志前请遮住个人路径、设备标识、密码、令牌和存档备份，不要公开发行密钥。

## 排错

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 智能体不能执行命令 | 运行环境不具备本机操作能力 | 换用支持 Skill 与命令执行的智能体 |
| 下载 404 | 仓库或 Release 附件未发布、名称不一致 | 确认仓库公开、标签和附件已发布；资源包见上文说明 |
| 无法连接电视 | IP 变化、ADB 未开、不同网段、路由器隔离、VPN | 核对当前 IPv4、开启 ADB、连接同一局域网；VPN 需允许局域网访问；不要将 ADB 暴露到公网 |
| 电视未授权 | 首次连接未确认 | 在电视弹窗点允许后重跑；脚本会复用待授权地址 |
| 无法安装 | 系统版本、ABI、空间、安装限制或签名冲突 | 逐项检查；签名冲突不要卸载重试 |
| 手柄无反应 | 未配对、电视未识别、按键映射不符 | 蓝牙先配对；在设置中查看手柄检测并重新绑定 |
| 游戏卡顿或无声 | 内核/ROM、性能、音频输出或音量 | 记录具体游戏和设备表现；检查游戏厅音量与电视输出 |
| 存档无法恢复 | 内核、游戏版本或文件被修改 | 使用同一内核与版本；跨内核即时存档不兼容 |
| 更新后存档消失 | 手动卸载、恢复覆盖了同名槽位 | 从备份恢复；恢复前确认目标设备 |
